maintainers). Covers the seven headline changes, Tier 1 SDK support
(TypeScript, Python, Go, C#, Rust beta), extensions framework launch
(Tasks, MCP Apps, EMA), and ecosystem quotes from AWS, Cloudflare,
Google Cloud, Microsoft, Figma, Honeycomb, Supabase, Xero, and others.

Reports nearly half a billion SDK downloads monthly; TypeScript and
Python SDKs each past 1 billion total downloads.
