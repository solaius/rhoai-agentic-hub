Referenced from the Agent Registry scoping doc as the companion scope document
for the Skills product. The agent registry's connection to skills is: an
agent's registry entry references which skills it carries; skills define
expertise, the agent registry governs which agents carry which skills. No
hard dependency -- agent entries describe capabilities directly in A2A schema;
skill references are enrichment, not prerequisite.

See [ref-agent-registry-scoping-gdoc](/components/agent-registry/knowledge/ref-agent-registry-scoping-gdoc.md).
