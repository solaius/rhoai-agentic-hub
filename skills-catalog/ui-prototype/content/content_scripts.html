Manage source

Configure which skills from this pre-loaded catalog source are visible in the skill catalog.

Name
Catalog YAML file
Skills

Optionally filter which skills from your source appear in the skill catalog. If no filters are set, all skills from the source will be visible.

Included skills

Enter skill names to include from this source. Separate names with commas. Use an asterisk suffix for prefix matching (Example: rh-sre*).

Excluded skills

Enter skill names to exclude from this source. Separate names with commas. Use wildcards for pattern matching (Example: *experimental*).
